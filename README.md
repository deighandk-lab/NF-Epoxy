# NF Epoxy — Five-Page Website

A professional, responsive website for **NF Epoxy**, a South African epoxy business based in Kempton Park, Gauteng.

## Current project status

The repository has been expanded from the original one-page foundation into the current five-page website architecture:

- **Home** — primary marketing and conversion page
- **About** — company positioning, history and practical-training philosophy
- **Products** — confirmed product areas with placeholders for future catalogue information
- **Services & Applications** — professional epoxy flooring and countertop applications
- **Workshops** — dedicated hands-on workshop page with interactive flip cards

There is intentionally **no Contact page or contact form**. WhatsApp is the primary conversion method.

## Development principles

1. Do not invent client information.
2. Preserve the NF Epoxy visual identity and do not distort or replace the client's logo.
3. Use approved client assets when supplied.
4. Keep shared CSS and JavaScript in `assets/css/style.css` and `assets/js/main.js`.
5. Keep navigation and relative paths correct for `/pages` files.
6. Test responsive behaviour, navigation, WhatsApp links, map loading and internal links before launch.
