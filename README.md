## Overview

This repository contains a modern multi-page website demonstration created for **NF Epoxy**.

The purpose of this project is to showcase how a professional website can improve an epoxy supplier's online presence, customer engagement and digital marketing.

> **This project is a demonstration concept and is not an official NF Epoxy website.**
