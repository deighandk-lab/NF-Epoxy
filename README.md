> **Project status:** Pre-deposit / preparation stage. This repository is a technical foundation and client presentation concept. It is **not yet the final production website** and should not be treated as an official NF Epoxy website until the client information, content and final approvals have been received.

## Project goal

The Phase 1 objective is to launch a polished, responsive one-page website for NF Epoxy by the agreed delivery period.

The one-page experience is structured around:

- Home / hero
- About NF Epoxy
- Product range
- Applications
- Why NF Epoxy
- Quote call-to-action
- Footer

The broader website can be expanded in a later phase once additional scope has been agreed and paid for.

## Development principles

This project follows a few simple rules during the preparation stage:

1. **Do not invent client information.** Unknown business details remain placeholders until confirmed.
2. **Keep Phase 1 focused.** The immediate goal is a strong one-page website, not a complete multi-page platform.
3. **Separate future scope.** Phase 2 functionality should not be activated prematurely.
4. **Use approved assets.** Client logos, photographs and product information should be added once supplied and approved for use.
5. **Test before launch.** Responsive behaviour, navigation, links, performance and accessibility should be checked before the production release.
